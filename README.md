# Portfólio Freelancer

## RESUMO DO PROJETO

**Portfólio Freelancer** é um projeto como o próprio nome sugere objetivo de permitir demonstrar 3 coisas: quem sou eu? o que já fiz? e o que eu posso fazer?. Neste site demonstro tudo que um potencial cliente precisa saber para determinar se sou a pessoa certa para desenvolver seu projeto.

### Depêndencias

As dependências do projeto podem ser encontrados no diretório backend no repositório no arquivo requirements.txt ou neste link: [Requirements.txt](https://github.com/Manasses-Ndombele/Portfolio-Freelancer/blob/master/requirements.txt)

### Instalação do projeto

`git clone https://github.com/Manasses-Ndombele/Borges-Company.git`

Instale o Python na sua máquina: [Python](https://www.python.org/)

```
pip install -r requirements.txt

python manage.py runserver
```

Acesse o projeto em seu navegador no endereço que aparecer no terminal

Se fores fazer alguma alteração de estilos do projeto siga esses passos também:

Instale o nodejs na sua máquina: [NodeJS](https://www.nodejs.org/downloads/)

Instale o Sass através do NPM:

`npm install -g sass`
